# عقود الواجهات الأساسية — UI V1

> الحالة: منفذة على الفرع `feature/phase6-ui-basic`؛ بانتظار اجتياز CI ومراجعة PR.
> امتداد QIR: `QIR-UI-OUTPUT-EXTENSION-1.2.md`.

## 1. النطاق

تغطي هذه الدفعة الأمرين المسجلين مسبقاً فقط: `UI.TEXT` و`UI.SHOW`. لا تضيف أسماء مكونات أخرى إلى Registry ولا تفترض اعتماد المقترحات التاريخية.

## 2. UI.TEXT — نص

- الاسم العربي: الواجهات.نص.
- النوع: عنصر إخراج نصي.
- الوسائط: وسيط واحد إلزامي من النوع `TXT`.
- المخرجات: لا توجد قيمة QX؛ يضاف عنصر فقرة نصية إلى سجل العرض.
- السلوك: يعرض النص كما هو، مع المحافظة على ترتيب التنفيذ.
- الرفض: الوسائط غير النصية أو عدد الوسائط غير الصحيح؛ لا يقبل كتعبير.
- الأمان: يعرض المتصفح المحتوى عبر `textContent` ولا يفسره كـHTML أو JavaScript.

## 3. UI.SHOW — عرض

- الاسم العربي: الواجهات.عرض.
- النوع: عنصر إخراج لقيمة.
- الوسائط: وسيط واحد إلزامي من الأنواع `NUM`, `TXT`, `BOOL`, `LIST`, `NULL`.
- المخرجات: لا توجد قيمة QX؛ يضاف سجل عرض من النوع SHOW.
- السلوك: يعرض النص مباشرة، ويعرض القيم الأخرى بتمثيل نصي مقروء، مع الحفاظ على ترتيب التنفيذ.
- الرفض: عدد الوسائط غير الصحيح؛ لا يقبل كتعبير.
- الأمان: لا ينفذ أي محتوى أو يحوله إلى HTML.

## 4. سلوك التشغيل

- يدعم VM سجلات إخراج مرتبة في `runQIR(...).outputs`.
- يدعم Web Backend إنشاء عناصر DOM نصية آمنة.
- تظهر مخرجات الدوال في نفس سجل التنفيذ وبترتيب استدعائها.
- لا تتيح هذه الأوامر تعديل عناصر سبق عرضها أو حذفها.
- لا توجد صلاحيات شبكة أو ملفات أو وصول إلى DOM اعتباطي أو تنفيذ شيفرة ديناميكية.

## 5. التوافق

- لا يستخدم QIR 1.0 أو 1.1 أوامري الواجهة.
- أي وحدة تستخدم UI.TEXT أو UI.SHOW تُصدر بصيغة QIR 1.2.
- يحافظ QIR 1.2 على دلالات QIR 1.0 وامتداد DATA 1.1.
- لا يتم تحديث مشاريع قائمة تلقائياً إلى إصدار جديد.

## 6. ما هو خارج النطاق

الأزرار والحقول والصور والنماذج والأحداث والتخطيطات المركبة وشجرة المكونات التفاعلية ليست جزءاً من هذه الدفعة. تحتاج كل منها إلى عقد مستقل ومراجعة صلاحيات واختبارات قبل إضافتها.
