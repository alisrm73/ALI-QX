# عقود مجموعة DATA — مسودة المراجعة الأولى

> الحالة: **مسودة مقترحة للمراجعة، وليست موافقة على تغيير التنفيذ أو تفعيل أوامر جديدة**  
> الأساس البرمجي: `main` بعد المرحلة الخامسة.  
> مواصفة QIR: `QIR V1` دون تعديل.  
> نطاق هذه الوثيقة: العقود التي يمكن اشتقاقها من السلوك الحالي فقط.

## 1. قرار النطاق

تغطي هذه المراجعة أربع عمليات موجودة في المسار الدلالي أو التنفيذي:

- `DATA.CREATE`
- `DATA.SET`
- `DATA.SET_GLOBAL`
- `DATA.COUNT`

لا تعتمد هذه الوثيقة عقوداً لـ `DATA.ADD` أو `DATA.REMOVE` أو `DATA.GET`. تبقى هذه الأسماء معلقة إلى أن تُحسم دلالاتها بشكل مستقل.

## 2. قواعد مشتركة

- المعرّف الداخلي ثابت ولا يتغير باختلاف اللغة.
- لكل عملية اسم إنجليزي واحد واسم عربي واحد، وفق سجل الأسماء الحالي.
- أنواع القيم المعروفة: `NUM`, `TXT`, `BOOL`, `LIST`. القيمة `NULL` ليست نوعاً أساسياً لاستنتاج نوع متغير.
- لا توجد تحويلات ضمنية بين الأنواع.
- المعرّفات تخضع لقواعد QX الحالية وتطبيع Unicode NFC.
- أخطاء النوع أو الاسم أو النطاق تُكتشف دلالياً قبل خفض البرنامج إلى QIR.
- لا تمنح هذه الوثيقة أي عملية صلاحية قراءة ملفات المضيف أو الشبكة أو تنفيذ شيفرة خارجية.
- الإصدار المقترح للعقود في هذه المسودة هو `0.1.0-draft`، وليس إصدار مكتبة منشوراً.

## 3. العقد: DATA.CREATE

| الحقل | العقد المقترح |
|---|---|
| المعرّف | `DATA.CREATE` |
| الاسم الإنجليزي | `CREATE` |
| الاسم العربي الحالي | `إنشاء` |
| الإصدار | `0.1.0-draft` |
| النوع | تعليمة تعريف متغير |
| الصيغة الحالية | `DATA.CREATE(identifier, initialValue)` |
| المدخل الأول | `identifier`: معرّف متغير، إلزامي |
| المدخل الثاني | `initialValue`: تعبير ينتج `NUM` أو `TXT` أو `BOOL` أو `LIST`، إلزامي |
| المخرج | لا توجد قيمة تعبيرية |
| الأثر | إنشاء متغير وتهيئته مرة واحدة |
| تحديد النوع | يستنتج من نوع التعبير الابتدائي |
| NULL | يرفض إذا كان التعبير الابتدائي `NULL` مباشرةً |
| النطاق | متغير محلي داخل الدالة، أو عام على مستوى الوحدة |
| التكرار | يرفض تكرار الاسم في النطاق نفسه |
| الظل | لا يسمح لمتغير محلي بحجب اسم متغير الوحدة وفق القاعدة الحالية |
| الاعتماديات | Lexer، Parser، Semantic Analyzer، QIR lowering، QIR validator، VM، Web Runtime |
| الصلاحيات | لا يحتاج صلاحيات خارجية |
| الحتمية | حتمي لنفس المصدر والسياق |
| أخطاء قائمة | `QX3017` وسيط غير صالح؛ `QX3018` تعذر استنتاج النوع من NULL؛ `QX3001` تكرار تعريف؛ `QX3036` تعذر استنتاج نوع فريد |
| الاختبارات المطلوبة | كل نوع مدعوم؛ قائمة فارغة ومختلطة؛ NULL المباشر؛ التكرار؛ النطاق؛ موضع الخطأ؛ توافق QIR وVM وWeb Runtime |

**حدود العقد:** لا تحدد هذه العملية قيمة افتراضية عند حذف المدخل الثاني؛ المدخلان إلزاميان. ولا تسمح بإعادة تعريف المتغير نفسه داخل النطاق نفسه.

## 4. العقد: DATA.SET

| الحقل | العقد المقترح |
|---|---|
| المعرّف | `DATA.SET` |
| الاسم الإنجليزي | `SET` |
| الاسم العربي الحالي | `تعيين` |
| الإصدار | `0.1.0-draft` |
| النوع | تعليمة إسناد لمتغير موجود |
| الصيغة الحالية | `DATA.SET(identifier, valueExpression)` |
| المدخل الأول | `identifier`: معرّف متغير موجود، إلزامي |
| المدخل الثاني | `valueExpression`: تعبير ينتج النوع نفسه للمتغير، إلزامي |
| المخرج | لا توجد قيمة تعبيرية |
| الأثر | تحديث قيمة متغير موجود دون تغيير نوعه |
| النطاق | يسمح بتحديث متغير محلي في الدالة، أو متغير الوحدة من مستوى الوحدة |
| داخل الدالة | لا يسمح بتحديث متغير الوحدة عبر `DATA.SET`؛ يستخدم `DATA.SET_GLOBAL` لهذا الغرض |
| النوع | يجب أن يطابق نوع التعبير نوع المتغير تماماً |
| المتغير غير الموجود | يرفض |
| الاعتماديات | Semantic Analyzer، QIR lowering، QIR validator، VM، Web Runtime |
| الصلاحيات | لا يحتاج صلاحيات خارجية |
| الحتمية | حتمي لنفس الحالة والمدخلات |
| أخطاء قائمة | `QX3003` متغير غير معرّف؛ `QX3020` محاولة تحديث متغير وحدة من دالة؛ `QX3022` اختلاف النوع؛ `QX3019` وسيطات غير صالحة |
| الاختبارات المطلوبة | تعيين صحيح لكل نوع؛ رفض اختلاف النوع؛ رفض غير الموجود؛ تحديث محلي؛ تحديث عام من مستوى الوحدة؛ رفض تحديث العام داخل دالة؛ تحقق قيمة الحالة في VM وWeb Runtime |

**حدود العقد:** لا تنشئ العملية متغيراً جديداً، ولا تغيّر نوع متغير قائم، ولا تعيد قيمة.

## 5. العقد: DATA.SET_GLOBAL

| الحقل | العقد المقترح |
|---|---|
| المعرّف | `DATA.SET_GLOBAL` |
| الاسم الإنجليزي | `SET_GLOBAL` |
| الاسم العربي الحالي | `تعيين_عام` |
| الإصدار | `0.1.0-draft` |
| النوع | تعليمة إسناد لمتغير وحدة عام موجود |
| الصيغة الحالية | `DATA.SET_GLOBAL(identifier, valueExpression)` |
| المدخل الأول | `identifier`: معرّف متغير وحدة موجود، إلزامي |
| المدخل الثاني | `valueExpression`: تعبير من النوع نفسه للمتغير، إلزامي |
| المخرج | لا توجد قيمة تعبيرية |
| الأثر | تحديث قيمة متغير وحدة موجود |
| النطاق المستهدف | متغير معلن على مستوى الوحدة فقط |
| النطاق المعتمد في هذه المراجعة | داخل الدوال فقط؛ يجب أن يكون الهدف متغير وحدة عام موجوداً |
| النوع | يجب أن يطابق نوع التعبير نوع المتغير تماماً |
| المتغير غير الموجود أو المحلي | يرفض |
| الاعتماديات | Semantic Analyzer، QIR lowering، QIR validator، VM، Web Runtime |
| الصلاحيات | لا يحتاج صلاحيات خارجية |
| الحتمية | حتمي لنفس الحالة والمدخلات |
| أخطاء قائمة | `QX3003` متغير غير معرّف؛ `QX3021` الهدف ليس متغير وحدة؛ `QX3022` اختلاف النوع؛ `QX3019` وسيطات غير صالحة |
| الاختبارات المطلوبة | تحديث global من دالة؛ رفض المحلي؛ رفض غير الموجود؛ رفض اختلاف النوع؛ التحقق من القيمة النهائية؛ تحقق VM وWeb Runtime |

**القرار المعتمد:** يقتصر `DATA.SET_GLOBAL` على الاستخدام داخل الدوال فقط. لا يُسمح باستخدامه على مستوى البرنامج الرئيسي. هذا القرار يغيّر السلوك الحالي الذي يسمح به المحلل الدلالي، ولذلك يتطلب لاحقاً تعديل Semantic Analyzer وQIR lowering وإضافة اختبارات رفض على مستوى الوحدة. لم يُنفذ هذا التغيير البرمجي بعد.

## 6. العقد: DATA.COUNT

| الحقل | العقد المقترح |
|---|---|
| المعرّف | `DATA.COUNT` |
| الاسم الإنجليزي | `COUNT` |
| الاسم العربي الحالي | `عدد` |
| الإصدار | `0.1.0-draft` |
| النوع | دالة أمرية ذات قيمة تعبيرية |
| الصيغة الحالية | `DATA.COUNT(listExpression)` |
| المدخل | تعبير واحد ينتج `LIST`، إلزامي |
| المخرج | `NUM` يمثل عدد عناصر القائمة |
| الأثر | قراءة فقط؛ لا تعدل القائمة |
| القائمة الفارغة | النتيجة `0` |
| القائمة المختلطة | مقبولة؛ نوع العناصر لا يغير طريقة العد |
| الاعتماديات | Semantic Analyzer، QIR `COMMAND_CALL`، VM، Web Runtime |
| الصلاحيات | لا يحتاج صلاحيات خارجية |
| الحتمية | حتمي؛ النتيجة هي طول القائمة |
| الحدود | تخضع القائمة لحدود الموارد المعتمدة في VM وWeb Runtime |
| أخطاء قائمة | `QX3013` عدد وسائط غير صحيح؛ `QX3014` المدخل ليس LIST؛ أخطاء التحقق/التنفيذ الخاصة بـ QIR وVM |
| الاختبارات المطلوبة | قائمة فارغة؛ عنصر واحد؛ عناصر متعددة؛ قائمة مختلطة؛ رفض غير LIST؛ رفض عدد وسائط غير صحيح؛ تطابق VM وWeb Runtime |

**حدود العقد:** لا تقوم العملية بإحصاء عناصر متداخلة أو جمع قيمها أو إزالة التكرارات؛ هي تعيد عدد العناصر المباشرة في القائمة فقط.

## 7. ملخص التوافق الحالي

| العملية | تحليل دلالي | خفض QIR | VM | Web Runtime | مفعّلة في Registry |
|---|---|---|---|---|---|
| `DATA.CREATE` | معالجة خاصة | DECLARE/STORE | عبر تعليمات QIR | عبر تعليمات QIR | لا |
| `DATA.SET` | معالجة خاصة | STORE_LOCAL/STORE_GLOBAL بحسب النطاق | عبر تعليمات QIR | عبر تعليمات QIR | لا |
| `DATA.SET_GLOBAL` | معالجة خاصة | STORE_GLOBAL | عبر تعليمات QIR | عبر تعليمات QIR | لا |
| `DATA.COUNT` | عقد صريح | COMMAND_CALL | تنفيذ مباشر | تنفيذ مباشر | نعم |

هذا الجدول يصف مسار التنفيذ الحالي ولا يغيّر حقيقة أن CREATE/SET/SET_GLOBAL لها معالجة خاصة وليست أوامر مفعلة في Registry.

## 8. مسائل تتطلب قرار المستخدم

1. **DATA.SET_GLOBAL — محسوم:** يقتصر على الدوال فقط، وفق موافقة المستخدم. التنفيذ البرمجي لم يبدأ بعد.
2. **أوامر القوائم التالية:** لم يُحسم ترتيب `DATA.GET` و`DATA.ADD` و`DATA.REMOVE`، ولا توجد عقود أو دلالات معتمدة لها حالياً.
3. **الاسم العربي:** يبقى الاسم الحالي `تعيين_عام` مؤقتاً إلى أن يُراجع ضمن اعتماد مواصفة DATA النهائية.

## 9. ما لم يتغير

- لم تتغير ملفات المصدر أو الاختبارات.
- لم يتغير سجل الأوامر أو حالة التفعيل.
- لم تتغير مواصفة QIR V1 أو VM أو Web Backend.
- لم تُضف عمليات GET/ADD/REMOVE.
- هذه الوثيقة مسودة مستقلة للمراجعة ولا تمثل اعتماداً نهائياً للعقود.

**بوابة الانتقال:** بعد اعتماد هذه العقود والقرارات المفتوحة، يمكن تحويلها إلى مواصفة DATA V1 نهائية، ثم تحديد تنفيذ مستقل واختبارات قبول قبل أي تغيير برمجي.
