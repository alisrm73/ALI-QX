## 1. القرارات المعتمدة

- مشروع ALI-QX يطوّر لغة برمجة مستقلة باسم QX، موجهة في الإصدار V1 لبناء مشاريع الويب.
- مجموعات المكتبة الأساسية أربع: UI وDATA وPROCESS وINTEGRATION. لا تُضاف مجموعة رئيسية خامسة دون قرار صريح.
- قواعد لغة QX V1 موثقة في `QX/README.md`، ومرجع Mathematics مستقل عنها.
- يعتمد المحرك QIR، مع فصل تنفيذ لغة QX عن توليد مواقع الويب وعن بناء أداة QX نفسها.
- Android هو المنصة الأساسية في المرحلة الحالية؛ Windows مؤجل بقرار المستخدم.
- لا يبدأ بناء مشروع من وصف المستخدم قبل عرض المخطط والحصول على موافقته.
- لا تُنفذ التغييرات الجوهرية أو التي توسع النطاق دون موافقة المستخدم.
- لا تُحذف أو تُنقل أو تُستبدل ملفات أو مكونات أو فروع قائمة دون إذن صريح.
- لا تُعد الميزة منفذة لمجرد توثيق تصميمها؛ يلزم تنفيذ واختبار ودليل مطابق.
- البرومبت الرئيسي الموجود تم تحديثه إلى الإصدار 2.0 بتاريخ 2026-11-16، دون إنشاء ملف بديل. Commit: `068d79fbc598bb9b63f5907994dc52521fe84ff9`.

## 8. التناقضات والنواقص التي تحتاج حسمًا

1. **حالة التكامل:** خارطة المراحل تسجل المرحلة 6 مكتملة، بينما خطة البنود الـ16 تسجل البند 7 (التكاملات الخارجية) متجاوزاً مؤقتاً وغير مغلق. يوجد Integration Broker واختباراته في الشجرة، لكن لم يظهر جرد محولات إنتاجية. يجب الحفاظ على هذا الفرق وعدم إعلان تكامل إنتاجي مكتمل.
2. **اختلاف الترقيم:** البند 8 في خطة البنود الـ16 هو محلل الأفكار (مغلق)، أما المرحلة 8 في خارطة المراحل 0–9 فهي QX Studio على Android (مكتملة عملياً في QX-Project). هذا اختلاف بين خطتين لا تعارض في الحالة.
3. **مولّد المشاريع:** البند 10 ما زال قيد التنفيذ. PR #54 وPR #55 مدمجان وCI ناجح على التغيير البرمجي الأخير، لكن مواصفة 7.7 ما زالت تحتوي معايير قبول غير مكتملة؛ لا إعلان إغلاق.
4. **المرحلة الثامنة:** Android العملي منفذ في مستودع QX-Project؛ PR #33 الخاص بمواصفة Kotlin/WebView أُغلق دون دمج بسبب التباعد وعدم قابلية الدمج. بقيت المواصفة على فرعها ولم تُدمج في main.
5. **أوامر اللغة:** `DATA.GET` وأوامر المضيف `QX.RUN/BUILD/TEST/STOP` تبقى معلقة/معطلة وفق العقود الحالية حتى استكمال شروطها المستقلة.
6. **الحماية:** لا تظهر فروع محمية في نتيجة الفروع، والتفاصيل غير قابلة للفحص بسبب 403؛ يلزم فحص يدوي من إعدادات GitHub قبل اعتبار حماية main مثبتة.
7. **الفروع:** فُحصت الفروع الـ57 غير main/backup بالمقارنة مع main وربطها بطلبات الدمج. حُددت 54 إحالة مرشحة للتنظيف و3 فروع تحمل تغييرات غير مدمجة. لا تتوفر عملية حذف فروع عبر موصل GitHub الحالي؛ لم يُنفذ الحذف.
8. **التوثيق العام:** تم تحديث حالة README وخطة البنود الـ16 لتطابق التطورات المدمجة. تبقى أقسام الإغلاق التاريخية في QX/README وخارطة المراحل كسجل تاريخي؛ عند التعارض يُرجع إلى أحدث سجل حالة وخطة البنود.

- تحديثه بعد كل تغيير مهم معتمد وبعد نجاح الفحوص ذات الصلة؛ لا يُحدّث تلقائياً مع كل تعديل صغير.
- لا تُجرى عليه أعمال تطوير اعتيادية ولا يُستخدم كقاعدة لطلبات ميزات.
- بعد كل تحديث، يجب التحقق أن SHA رأس `نسخ-احتياطية` يطابق SHA رأس `main`.
- لا يُستخدم للاستعادة فوق main إلا بقرار صريح، مع مراجعة الفرق قبل أي تحريك قسري.

## 10. قواعد تحديث هذا السجل

1. يضاف القرار إلى القرارات المعتمدة بعد موافقة المستخدم فقط.
2. تسجل المقترحات غير المعتمدة بوضوح ولا تخلط بالقرارات.
3. عند تسجيل إنجاز، يذكر ما نُفذ وما اختُبر ونتيجة الاختبار ورابطه أو SHA عند توفره.
4. تسجل المشكلات والنواقص المفتوحة دون الادعاء بحلها.
5. لا يحذف قرار سابق أو يستبدل بصمت؛ يوثق أي تغيير وسببه وتاريخه.
6. يبقى هذا الملف السجل الموحد للملاحظات والجرد؛ لا يُنشأ ملف جرد أو سجل موازٍ.
